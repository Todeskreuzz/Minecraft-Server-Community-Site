# Quellen & externe Dienste

- [GitHub Pages Dokumentation](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) – GitHub Pages für öffentliche Repositories im Free-Plan.
- [Cloudflare Pages: statisches HTML](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/) – Hosting statischer Dateien ohne Framework.
- [Cloudflare Pages: Git-Integration](https://developers.cloudflare.com/pages/get-started/git-integration/) – Deployments aus GitHub.
- [mcstatus.io API](https://mcstatus.io/docs) – optionaler Java-Serverstatus, nach Einrichtung einer Server-IP.
- [CurseForge App](https://www.curseforge.com/download/app) – Import von CurseForge-Profilen.

Die visuellen Vektoren, Logos, Layouts, Animationen, CSS- und JavaScript-Quellen dieses Projekts wurden eigens für diese Seite erstellt. Keine von Dritten eingebundenen Bilder, Fonts oder Design-Abhängigkeiten.
